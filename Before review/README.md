# Orphan Management System — Before Review

This folder contains early project framing.

## Project name

Baitulmaal Orphan Management System (OMS)

## Simple description

A module of the Baitulmaal PMO Platform that registers and verifies orphans, matches them with sponsors, tracks support and funds delivered to each orphan, and sends approved, privacy-reviewed progress reports to sponsors.

## Core flow

**Partner / Country Office → Reviewer → Program Manager → Sponsorship → Field Office → Finance → Sponsor**
